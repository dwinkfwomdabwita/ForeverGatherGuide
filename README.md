# Gather Forever (WoW: Forever addon)

Every profession in WoW: Forever: map routes, every trainer, live auction house prices, the cheapest path to 300, gear you can craft, and the best ways to make gold.

## ⬇️ Download

**[Download the latest version (GatherForever.zip)](https://github.com/dwinkfwomdabwita/GatherForever/releases/latest/download/GatherForever.zip)**

Also on CurseForge as **Gather Forever** (once it's approved), so the CurseForge app can keep it updated for you.

## How to install

1. Close WoW.
2. Open the zip. Inside is a folder called `GatherForever`.
3. Drag that folder into your game's AddOns folder: `World of Warcraft\_forever_\Interface\AddOns` (the path should end in `AddOns\GatherForever\GatherForever.toc`).
4. If you had the old **Forever Gather Guide**, delete the `ForeverGatherGuide` folder.
5. Start the game and type `/gf`, or click the Peacebloom minimap button.

Updating: delete the old `GatherForever` folder, then do the steps again with the new zip.

## What it does

- **Gathering:** Mining, Herbalism, Skinning, Fishing and Cloth - best zones per skill bracket and map routes you can follow, with a built-in direction arrow.
- **Crafting:** the cheapest path to 300 for every crafting profession (routes A and B) at today's AH prices, with a shopping list. Hover any material to see what it's made from.
- **Gear for you:** craftable gear your class can use, scored for your spec and compared with what you wear.
- **Gold Grinds:** the best money makers for each profession, with live prices.
- **Trainers, quests, camping and blueprints,** Gnomish and Goblin Engineering, alts and mail counts, gold on all characters, and your farming runs.

Optional extras (not required): Auctionator, TradeSkillMaster, MinimapButtonButton.
