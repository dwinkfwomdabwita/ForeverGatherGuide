# Forever Gather Guide (WoW: Forever addon)

Every profession in WoW: Forever: map routes, every trainer, live auction house prices, and the cheapest path to 300.

## How to install

1. Close WoW.
2. Open the zip. Inside is a folder called **ForeverGatherGuide**.
3. Drag that folder into your game's AddOns folder: `World of Warcraft\<your Forever game folder>\Interface\AddOns`
   (Don't put it inside another folder: the path should end in `AddOns\ForeverGatherGuide\ForeverGatherGuide.toc`.)
4. Start the game. On the character screen, click **AddOns** and make sure Forever Gather Guide is ticked.
5. In game, type `/gg` or click the Peacebloom minimap button.

**Updating:** delete the old ForeverGatherGuide folder, then do the steps again with the new zip.

## What it does

- **Gathering:** Mining, Herbalism, Skinning, Fishing and Cloth, with the best zones for each skill bracket and map routes you can follow.
- **Crafting:** the cheapest path to 300 for every crafting profession at today's auction house prices, with a shopping list.
- **Trainers and quests:** every profession trainer and profession quest, with waypoints.
- **AH Planner:** live prices, cost to 300, and the best crafts to sell right now.

Optional extras (not required): Auctionator, TradeSkillMaster, TomTom, MinimapButtonButton.
